# Asphalt Outlaws — design spec & implementation plan

A Road Rash–style pseudo-3D motorcycle racer with combat, built for this
monorepo per [`docs/GAMES.md`](../docs/GAMES.md): bun + Vite + TypeScript
strict + Canvas2D + WebAudio, **zero binary assets** (everything procedural),
pure-logic `bun test` suites, one shared Pages deploy workflow.

Stack: TypeScript strict, Vite 5 (`base: "./"`), Canvas2D rendering, WebAudio
sfx/engine, seeded RNG, fixed-timestep sim (60 Hz) with decoupled render.

---

## 1. Concept

Illegal street motorcycle races. You and 7 rivals hammer down a long
point-to-point highway. You can punch and kick rivals off their bikes, dodge
same-direction traffic and oncoming cars, and eat asphalt if you mess up.
Finish high enough to advance through a 5-race ladder. Cops join later races
and try to bust you.

- **One player** + 7 rivals (+ up to 2 cop riders from race 3).
- **Point-to-point race** (no laps): cross the finish line first.
- **Combat**: attacks land on riders alongside you; damage builds toward a
  knockdown; knockdowns cost the victim huge time. You can be knocked down too.
- **Crashes**: hit traffic or run off-road at speed and you wipe out (tumble,
  remount with brief invulnerability). HP reaching 0 = wrecked = DNF.
- **Busted**: if a cop stays alongside you while you're slow, you get busted.
- **Economy**: prize money per race, scaled by finishing place.

## 2. Controls

| Key | Action |
|---|---|
| `W` / `↑` | throttle |
| `S` / `↓` | brake |
| `A`/`D` / `←`/`→` | steer |
| `J` / `Z` | attack LEFT |
| `K` / `X` | attack RIGHT |
| `Enter` | confirm / start |
| `Esc` / `P` | pause / back |

Attacks hit whichever rider is in range on that side (rivals or cops).

## 3. Race ladder (config-driven)

| # | Name | Length (segs) | Feel | Rivals | Cops | Qualify | Prize |
|---|---|---|---|---|---|---|---|
| 1 | Pacific Run | 4000 | gentle curves, palms, day | 7 easy | 0 | top 5 | $1500 |
| 2 | Dust Devils | 4600 | desert, cactus, rolling hills | 7 | 0 | top 4 | $3000 |
| 3 | Sunset Strip | 5200 | dusk city, signs/lamps, traffic heavy | 7 | 2 | top 3 | $5000 |
| 4 | Canyon Rush | 5800 | sharp curves, canyon walls, night | 7 faster | 2 | top 3 | $8000 |
| 5 | Frostbite Pass | 6500 | snow, fog, brutal traffic + cops | 7 fastest | 2 | top 2 | $12000 |

Fail a race → retry it (keep money). Win the ladder → credits screen.

## 4. Architecture

Fixed-timestep sim (`SIM.step = 1/60`) producing a fully serializable
`RaceState`; rendering reads state and never mutates it. All randomness flows
through `RNG` seeded **per race** (never per page load — GAMES.md gotcha).

```
src/
  main.ts            boot: canvas, app state machine, loop, input, audio wiring (ORCHESTRATOR)
  config.ts          ALL gameplay tunables (ORCHESTRATOR)
  core/
    rng.ts           seeded mulberry32 RNG (ORCHESTRATOR)
    math.ts          clamp/lerp/ease/approach helpers (ORCHESTRATOR)
    loop.ts          fixed-step accumulator loop w/ rAF (ORCHESTRATOR)
    input.ts         keyboard -> InputState snapshot (ORCHESTRATOR)
  sim/               PURE logic — no DOM, no canvas, importable from bun tests
    types.ts         shared types (ORCHESTRATOR)
    track.ts         buildTrack, findSegment, trackLength, projection math   [AGENT A]
    bike.ts          player physics: accel/brake/steer/centrifugal/offroad  [AGENT B]
    combat.ts        attacks, hit resolution, knockdowns, wobble, busting   [AGENT B]
    crash.ts         crash/tumble/remount/invulnerability state machine     [AGENT B]
    rider-ai.ts      rival brains: line choice, drafting, attacks, avoidance [AGENT C]
    traffic.ts       spawn/recycle/move traffic, collision checks           [AGENT C]
    race.ts          createRace, places, finish/qualify/results, flow       [AGENT C]
    world.ts         createWorld/stepWorld: composes all of the above       [ORCHESTRATOR]
  render/
    road.ts          camera, projection, road/terrain/fog drawing           [AGENT A]
    sky.ts           sky gradient + parallax backdrop per palette           [AGENT A]
    scenery.ts       roadside object drawing (palms, cacti, signs, lamps)   [AGENT A]
    sprites.ts       procedural cached sprites: riders, bikes, traffic      [AGENT D]
    rider-view.ts    draw riders in poses (ride/lean/punch/hit/down)        [AGENT D]
    hud.ts           canvas HUD: speedo, place, progress, HP, toasts        [AGENT D]
    fx.ts            particle system (sparks, dust, tumble stars, snow)     [AGENT D]
  ui/
    state.ts         AppModel: title/select/race/results/pause/gameover     [AGENT D]
    screens.ts       DOM screens in #overlay-root (title, bike select, ...) [AGENT D]
  audio/
    audio.ts         WebAudio engine loop + sfx (procedural)                [AGENT D]
tests/               bun test, pure logic only (no DOM)
```

`AGENT A/B/C/D` = implemented by sub agents against the contracts below; all
other files are provided. **Ownership is strict: an agent never edits a file
it doesn't own.**

## 5. Contracts (already written — import, don't redeclare)

`src/sim/types.ts` and `src/config.ts` are complete and final. Every module
stub exists with the exact exported names to implement. Summary of the
function-level contract each owner implements:

### Agent A — track + background render
- `sim/track.ts`: `buildTrack(level, rng): TrackData` (straight/easeIn/hold/
  easeOut curve sections + hills from the level spec, scenery placement into
  `TrackData.scenery`, start line + finish line colors), `findSegment`,
  `trackLength`, `projectPoint` (Jake-Gordon-style world→screen projection
  mutating a `ProjPoint`), `computeCamDepth(fov)`.
- `render/road.ts`: `updateCamera`, `renderWorld` (fog, grass strips, rumble,
  lanes, finish stripe; segments back-to-front are drawn far→near by caller:
  renderWorld draws everything incl. scenery via `render/scenery.ts`), and
  `projectForSprite(state, cam, z, offsetX)` used by Agent D to place riders.
- `render/sky.ts`, `render/scenery.ts`: palette-driven backdrop + roadside
  props (procedural draw, cheap, no gradients-heavy per-frame allocation).

### Agent B — player sim + combat + crash
- `sim/bike.ts`: `stepPlayer(player, input, dt, ctx)` — accel/brake/decel,
  steering with speed-scaled rate, centrifugal drift from segment curve,
  off-road detection & drag, wobble steering interference, clamp `x` to
  [-2.2, 2.2] road-half-widths, advance `z` by speed·dt, world-loop modulo.
- `sim/combat.ts`: `tryAttack(attacker, side, state, ctx)` (start swing if a
  target is in range), `resolveCombat(state, ctx)` (pairwise proximity checks,
  damage, wobble, knockdown rolls, cop bust logic, HP regen for clean riding,
  event emission), helpers `inStrikeRange`.
- `sim/crash.ts`: `startCrash(victim, cause, ctx)`, `stepDowned(victim, dt,
  ctx)` (tumble, friction stop, timer, remount with `invulnT`, emit events).

### Agent C — rivals, traffic, race flow
- `sim/rider-ai.ts`: `spawnRivals(level, rng)` (7 rivals + level cops, spread
  near start line), `stepRival(r, state, ctx)` — target speed with rubber-
  banding by skill, steer to racing line w/ curve anticipation, avoid traffic
  & riders, attack player (and each other rarely) by aggression, cops hunt the
  player and try to hold alongside while the player is slow.
- `sim/traffic.ts`: `spawnTraffic(level, rng, track)`, `stepTraffic(state,
  ctx)` (move both directions, recycle past camera), `checkTrafficHit(rider,
  state)` — returns the car hit or null.
- `sim/race.ts`: `createRace(cfg)` (build track via A, spawn via B/C, initial
  state incl. seeded RNG), `updatePlaces(state)` (rank by z among finished),
  `stepRaceFlow(state, ctx)` (countdown → racing → finish crossing → results
  with prize/qualify per level; busted/wrecked endings), `computeResults`.

### Agent D — view + UI + audio
- `render/sprites.ts`: cached procedural sprite canvases keyed by pose+color:
  rider (bike side/back view with lean & combat poses), traffic (car/truck/bus
  front/back), drawn at native ~128px then scaled. No text in sprites.
- `render/rider-view.ts`: `drawRiders(g, state, cam)` — project each rider via
  A's `projectForSprite`, pick pose from rider state (lean/attack/down/hit
  flash), draw back-to-front, player last & biggest; downed riders tumble
  (rotate + slide) via `fx.ts` data. Also `drawTraffic(g, state, cam)`.
- `render/hud.ts`: `renderHud(g, state, meta)` — analog speedo arc + digital
  mph, place `3/8`, race progress bar with rival ticks, HP bar (player +
  nearby rival mini-bar), countdown numerals, toast messages, minimap strip.
- `render/fx.ts`: `ParticleSystem` with `emit(name, x, y)`, `step(dt)`,
  `draw(g)`; presets: sparks, dust, smoke, snow, stars(knockdown), speedlines.
- `ui/state.ts`: `AppModel` — phases `title | select | results | gameover |
  credits | paused`, holds `career {levelIdx, money}`, exposes `startRace()`,
  `finishRace(results)`, input-driven `confirm/back`, events for main.ts.
- `ui/screens.ts`: DOM builders for `#overlay-root`: title (logo, "press
  enter"), bike select (3 bikes with stat bars, left/right), results card,
  game over, credits. Match aesthetic: chunky retro arcade (see §7).
- `audio/audio.ts`: `AudioEngine` — `unlock()` on first gesture, engine loop
  (osc pitch/gain by rpm), sfx: punch, kick, hit, knockdown, crash, countdown
  beep/go, siren (cops present), ui move/confirm, finish fanfare. Mute toggle
  `M`.

## 6. Sim rules (normative)

- Units: world `z` along track (1 segment = `SIM.segmentLength`), lateral `x`
  in road-half-width fractions [-1..1] on road.
- `maxSpeed = SIM.segmentLength / SIM.step` (one segment per tick ≈ 12000 u/s)
  scaled by bike `topSpeedMul` and level cap; off-road limit 25% of max.
- Speed→MPH display: `mph = speed / 120` (tuned so top ≈ 190 mph).
- Combat range: |Δz| ≤ 300, side offset 0.15..0.9 road-half-widths on attack
  side. Punch 22 dmg / kick 34 dmg, both add wobble 0.4/0.55. Knockdown when
  hp ≤ 0 or (wobble ≥ 1 and speed > 0.4·max). Downed ~2.4 s, speed → 0.
- Player HP 100; regen +2/s while riding clean (no hits given/taken for 4 s).
  HP 0 → wrecked (DNF). Remount invulnerable 2 s.
- Cop bust: cop within combat range and player speed < 30% max for 1.5 s
  cumulative → busted. Shake cops with attacks or speed.
- Places: rank by `z` (finished riders keep finish order). Qualify per ladder.
- Determinism: every rng draw from the race-seeded RNG; no `Math.random` in
  `sim/` (a `bun test` guard checks this by running two seeded worlds).

## 7. Look & feel

Pseudo-3D "superbike" arcade: saturated dusk palettes, chunky shapes, strong
horizon, palm/cactus/lamp silhouettes, road with rumble strips and center
dashes, fog to horizon color. UI: chrome-and-neon arcade poster style —
angled panels, thick borders, condensed uppercase headings (system fonts
only: `"Arial Black", Impact, ...`), accent orange `#ff5b2e` on deep purple
`#16101f`, cream ink `#f5ead6`. Canvas HUD mimics 90s arcade gauges. No
external fonts, no images, no emoji in the UI.

## 8. Tests (bun, pure logic)

- `tests/track.test.ts` (A): segment count/length, curve continuity, hills
  bounded, scenery within bounds, finish segment exists, findSegment stable.
- `tests/bike.test.ts` (B): accel approaches max, braking faster than coast,
  steering clamped, centrifugal pushes outward on curves, off-road slows.
- `tests/combat.test.ts` (B): range gating per side, damage & wobble applied,
  knockdown on hp 0, cooldowns, bust timer with cop, HP regen gating.
- `tests/crash.test.ts` (B): crash zeroes speed, tumble timer remounts with
  invuln, wrecked at hp 0.
- `tests/traffic.test.ts` (C): spawn count by density, both directions,
  recycling keeps counts, collision detected only near rider z/x.
- `tests/rider-ai.test.ts` (C): rivals progress in racing phase, avoid lane
  with traffic, cops approach player, no NaN over 5000 steps.
- `tests/race.test.ts` (C): countdown → racing transition, places ordered,
  finish sets results + prize + qualify, busted/wrecked endings.
- `tests/world.test.ts` (orchestrator): seeded determinism (two worlds, same
  seed & scripted input → identical states), no NaN over 20k ticks.
- `tests/rng.test.ts`, `tests/math.test.ts` (orchestrator, baseline).

Run: `bun test` from the game folder. Keep suites fast (<1 s each).

## 9. Verification & ship (orchestrator)

`tsc --noEmit` + `bun test` green → `bun run build` → live pass with
`playwright-cli` on headless Chromium against `bun run preview` (console
clean, title → select → race → HUD visible, screenshots to /tmp) → docs →
register in hub/workflow/GAMES.md/README → commit → push → watch Pages run →
curl play URL + assets 200.

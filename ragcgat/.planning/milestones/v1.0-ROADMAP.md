# Milestone v1.0: MVP — Import, Browse, Search

**Status:** ✅ SHIPPED 2026-09-12
**Phases:** 1-5
**Total Plans:** 11

## Overview

RagChat v1.0 delivers the complete local-first WhatsApp archive loop: drag-drop a .txt (or .zip) export, preview and confirm the import into IndexedDB with deterministic dedup, browse conversations in a WhatsApp-style capped-window chat UI, and keyword-search across all chats or within one — with highlighted results, exact counts, and deep-linkable scroll-to-message navigation. Fully client-side (SvelteKit 5 + Svelte 5 runes + Dexie 4 + Tailwind 4), static build, no backend.

## Milestone Summary

**Key Decisions:**

- Dexie multiEntry over Orama for v1 search (Rationale: query layer already built+tested since schema v1, zero deps, native persistence; v2 RAG needs its own vector storage regardless)
- Custom ~40-line parser over unmaintained npm packages (Rationale: 14+ format families need first-class tolerance)
- Capped-window rendering over full virtualization for v1 (Rationale: 120 rows ≤ 200 budget covers 100K-message chats via keyset pagination)
- trimToBudget keeps OLDEST pages (Rationale: monotonic keyset frontier; newest re-reachable on reopen)
- Dev port 4647 — RAGCHAT in leetspeak (user pick)
- svelte-check added to the standard gate set (catches undeclared-name bugs tsc/tests/build miss)

**Issues Resolved:**

- Windowing trim-direction keyset loop (Phase 4 UAT)
- flex-chain page-scroll leak breaking pane anchors (Phase 4 UAT)
- Invalid `{@html}` search-result rendering caught by svelte-check before ship (Phase 5)

**Issues Deferred (v2 candidates):**

- Per-chat vs global dedupHash scope decision (N6)
- >100-chat selection bound on deep links (N8)
- Own-message right-alignment ('me' concept) (N9)
- First-import done-banner reachability (N7)

**Technical Debt Incurred:**

- Dead-in-prod exports: importChatText, observeLatest, anchorDelta/isSameDay (test-only)
- Inert v2-migration `day` column; unread worker `{bytes, lines}` stats payload
- Parser file naming drift vs roadmap export map (capability complete)

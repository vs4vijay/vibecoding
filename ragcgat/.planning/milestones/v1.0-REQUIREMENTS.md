# Requirements Archive: RagChat v1.0

**Milestone:** v1.0 (Shipped 2026-09-12)
**Outcome:** 13/13 v1 requirements complete. All verified via per-phase UAT artifacts (including two manual browser passes on the live dev origin) and a cross-phase integration audit (4/4 flows PASS).

## v1 Requirements — Final Status

### Import

- [x] **IMPR-01**: User can drag and drop WhatsApp .txt export files onto the app — Phase 3 (03-UAT + browser drop)
- [x] **IMPR-02**: User can select WhatsApp .txt export files via file picker — Phase 3
- [x] **IMPR-03**: User sees a preview of detected messages before import confirms — Phase 3 (new/skipped diff)
- [x] **IMPR-04**: System parses WhatsApp export format into structured messages — Phase 1 (24-fixture benchmark)
- [x] **IMPR-05**: System detects existing chat and upserts (creates new or merges) — Phase 3 (name-scoped merge, max-merge stats)
- [x] **IMPR-06**: System stores all data locally in IndexedDB — Phase 2 (Dexie v1-v3 migrations, persistence request)

### Chat Browsing

- [x] **BROW-01**: Sidebar lists all imported conversations by recency — Phase 4 (liveQuery on indexed lastMessageAt)
- [x] **BROW-02**: Click opens chat-style bubble view — Phase 4 (capped window, ?chat= deep links)
- [x] **BROW-03**: Sender name, timestamp, WhatsApp-style layout — Phase 4 (sender palette, clocks, day dividers)
- [x] **BROW-04**: Media attachments show typed placeholders — Phase 4 (6 placeholder types, event rows)

### Search

- [x] **SRCH-01**: Search across all conversations by keyword — Phase 5 (exact count, newest-first, highlighted)
- [x] **SRCH-02**: Search within a specific conversation — Phase 5 (scoped surface)
- [x] **SRCH-03**: Results show context and link back to the conversation — Phase 5 (snippets, ?chat&at deep link, scroll-to-message)

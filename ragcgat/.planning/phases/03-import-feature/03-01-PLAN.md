<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file picker plus drop zone to validator | User-controlled File name, size, and bytes cross here |
| main thread to worker | Transferred ArrayBuffer crosses here; only buffers transfer, strings clone |
| worker preview to Dexie commit | Parsed text treated as untrusted display content until escaped render |
| npm registry to local install | svelte, kit, adapter-static, tailwind, vite, fflate enter the supply chain via bun add |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | svelte, kit, adapter-static, tailwind, vite, fflate tarballs | high | mitigate | Blocking human checkpoint verifies each package on npmjs.com before install; versions pinned per RESEARCH.md audit |
| T-03-02 | Denial of service | oversize .txt file | medium | mitigate | validateFile rejects zero-byte and over-25MB inputs before any read; worker transfer keeps memory flat |
| T-03-03 | Cross-site scripting | message text rendered in preview samples | high | mitigate | Plain escaped interpolation only; never at-html on chat, file, or zip content; samples are truncated display strings |
| T-03-04 | Spoofing | renamed binary or evil.txt.exe | medium | mitigate | Extension gate plus parse-success gate in worker error path; unparseable input yields user-facing error with zero writes |
| T-03-05 | Denial of service | re-import flooding same file | low | mitigate | dedupHash idempotency via bulkSave pre-query; re-commit writes 0 and messageCount bumps by written only |
| T-03-SC | Tampering | bun installs | high | mitigate | Human checkpoint gates all installs; T-03-01 covers verification |
</threat_model>

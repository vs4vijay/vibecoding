<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parser output to bulk writer | Parsed text untrusted for index size; tokenizer truncation and term caps bound the write amplification |
| cursor values to pagination queries | Cursor originates from previously returned rows; malformed cursors must not cause full scans |
| v1 database to upgraded schema | Upgrade transaction runs against user data that must survive intact |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Denial of service | bulkSave with adversarial large imports | medium | mitigate | Fixed 500-size chunks bound transaction memory; per-chunk error isolation prevents one bad batch from aborting the import |
| T-02-06 | Denial of service | searchTerms with hostile query strings | low | mitigate | Shared tokenize truncates and caps query tokens; every query ends in limit so result sets stay bounded |
| T-02-07 | Tampering | upgrade() modify callback | medium | mitigate | Backfill callbacks stay pure and synchronous; upgrade errors roll back the whole transaction rather than partial-writing |
| T-02-08 | Information disclosure | dedupHash reuse as identifier | low | accept | Hash is a dedup key only, never presented as a security control and never leaves the local database |
| T-02-09 | Denial of service | unbounded reads on large chats | medium | mitigate | Keyset cursors with limit on every read path; grep gate in verification rejects unbounded toArray in non-test code |
</threat_model>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Cross-site scripting | message bodies, sender names, chat names in sidebar and bubbles | high | mitigate | Escaped interpolation only; {@html} banned in every Phase 4 component; linkification deferred |
| T-04-02 | Tampering | ?chat= selection param | medium | mitigate | Strict integer parse in selection.ts, unknown ids render empty state; ids used only as Dexie primary-key gets, never string-concatenated |
| T-04-03 | Tampering | v3 migration backfill over user data | high | mitigate | Bounded per-chat indexed reads, fallback to importedAt, idempotent skip of migrated rows; migration integration tests pin all four paths before merge |
| T-04-04 | Denial of service | unbounded message reads in ChatView | medium | mitigate | Capped window via PAGE_SIZE 40 getLatestWindow/getOlderPage keyset reads only; no toArray on messages without a [chatId+timestamp] bound; full virtualization budget enforced in 04-02 |
| T-04-05 | Information disclosure | chat names rendered from exports | low | mitigate | Names rendered as escaped text only, never as HTML or attributes |
| T-04-06 | Tampering | localStorage ragchat:theme cache poisoning | low | mitigate | Allow-list of light and dark only; anything else falls back to system default |
| T-04-SC | Tampering | bun installs | high | mitigate | No installs in this plan; zero-new-deps per RESEARCH.md audit (svelte-virtual-list SUS disposition honored — never installed) |

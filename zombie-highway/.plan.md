# UNDEAD HIGHWAY — Design Spec (v1)

> Endless zombie-highway survival web game. Homage to Auxbrain's *Zombie Highway* (2010 iOS, 2012 Android). Web-first (desktop + mobile browsers), no install.

## 1. Core Loop

```
Drive fast ──► zombies LEAP onto your sides ──► car TIPS as weight builds
     ▲                    │                            │
     │            SHOOT them off (tap side)      tilt held past limit?
     │            or SCRAPE them on obstacles          │
     │                    │                            ▼
     └──── score climbs ◄──┘                      FLIP = game over
              every score threshold → LEVEL UP → more/faster zombies
```

Death is always the player's fault and always dramatic. Restart must take < 300 ms from game-over tap to driving. The "one more run" hook is the product.

## 2. Mechanics

### 2.1 Driving
- Auto-throttle down an endless divided desert highway at dusk.
- **Continuous analog steering** (not lane-snapped): horizontal drag with pointer, or A/D and arrow keys.
- Cruise speed creeps up automatically with level; steering does not affect speed.

### 2.2 Zombie leaps
- Zombies spawn on road shoulders ahead, crouch-flash a **0.35 s telegraph**, then leap at the car's predicted position.
- Dodge by steering away; a missed leap tumbles away harmlessly.
- Clinging zombies add side weight: Walker 1, Runner 1, Brute 2.

### 2.3 Weight & tipping
- Side imbalance ≥ capacity starts tipping the car — roughly a 1.2 s window to save it by killing/scraping zombies.
- HUD shows a leaning car-silhouette gauge flashing red near critical.

### 2.4 Shooting
- Tap/hold **left/right screen half** (or `,` `.` keys) fires that side's gun: 8-round magazine, 1 s auto-reload, fire-rate cap.
- Recently-leaped zombies take double damage (original game's trick).

### 2.5 Scraping
- Graze wrecks/barriers/edge rails laterally → sparks, clinging zombies on that side take heavy damage or rip off; costs speed and adds camera shake.
- Head-on into a big obstacle = instant crash death.

### 2.6 Deaths
- Two deaths only: **flip** (imbalance held too long) or **head-on crash**.
- Slow-mo death cam, then stats card (score, distance, kills, level).

### 2.7 Score
- Meters traveled + kill points (Walker 25 / Runner 50 / Brute 150).
- Scrape-kills score ×2; kill-streak multiplier ×2–×4 decaying after 4 s without a kill.
- Best score + best distance persisted in localStorage.

## 3. Difficulty Thresholds

- Level = f(score), curve `req(n) ≈ 400·n^1.35` (fast early level-ups, slower grind later).
- Each LEVEL UP: banner + audio sting + brief slow-mo beat, then:
  - spawn interval ↓, max concurrent zombies ↑, leap accuracy/range ↑
  - cruise speed ↑, obstacle density ↑
  - new types unlock: L2 Runner, L3 Brute; beyond = stat inflation
- Hard caps on all knobs so late game stays hard but fair.

## 4. Look & Feel

- Low-poly geometry only, **zero image assets**: burnt-orange dusk sky, fog-masked draw distance, sodium streetlamps strobing past, ruined-city skyline, cracked asphalt, boxy muscle car with body roll/pitch, glowing headlight cones.
- Zombies: chunky low-poly humanoids; red particle bursts; ragdoll tumble on kill/miss.
- Camera: chase-cam with speed-based FOV kick, shake on impacts; CSS vignette overlay.
- Audio: WebAudio-synthesized (engine pitch ∝ speed, gunshots, groans, heartbeat drone while tipping, level-up sting). Mute toggle persisted.

## 5. Architecture

```
zombie-highway/
  index.html               fullscreen canvas + HUD DOM overlay
  src/
    config.ts              ALL tunables (single balance file)
    main.ts                boot, resize, RAF loop (fixed-step sim)
    core/                  input (pointer+keys unified), audio synth, storage
    game/                  state machine (TITLE→RUN→OVER/PAUSE), session,
                           car physics, zombies, obstacles, spawner,
                           difficulty director, scoring, collisions
    render/                three scene graph, pooled meshes (car/zombies/road/FX),
                           camera rig
    ui/                    HUD, menus, coach overlay
  tests/                   vitest: difficulty thresholds, tilt math, scoring,
                           spawn-path guarantee
```

- Plain pooled classes over ECS (~30 live entities); Three.js for 3D; HUD in DOM for crisp text.
- Object pools for zombies, obstacles, particles, road segments — zero steady-state allocation.
- Blob shadows, no shadow maps; pixel-ratio clamp; target 60 fps mid-range phones.
- Fixed 60 Hz simulation step decoupled from render.
- Mobile input contract: horizontal drag anywhere = steer; quick tap (<200 ms, <10 px) on a screen half = fire that side. One-time coach overlay (localStorage flag).
- Auto-pause on tab blur. Deploys as static files anywhere.

## 6. Controls

| Action | Touch | Desktop |
|---|---|---|
| Steer | horizontal drag anywhere | A/D or ←/→ |
| Shoot left | tap left half (<200 ms, <10 px) | `,` |
| Shoot right | tap right half | `.` |
| Pause | pause button | Esc/P |
| Start/restart | big button | Space/Enter |

## 7. Out of Scope (v1)

Coins/currency, unlockable cars/weapons, nitro, online leaderboards, device-tilt steering, PWA/offline packaging.

```ts
import { CONFIG } from "../config";
const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));
const D = CONFIG.difficulty;

export type ZombieType = keyof typeof CONFIG.zombies;
export type Knobs = {
  level: number; spawnIntervalMs: number; maxZombies: number;
  leapAccuracy: number; cruiseSpeed: number; obstacleDensity: number; types: ZombieType[];
};

export function scoreForLevel(n: number): number {
  if (n <= 1) return 0;
  return Math.round(D.baseReq * Math.pow(n - 1, D.exp));
}
export function levelForScore(score: number): number {
  let lvl = 1;
  while (scoreForLevel(lvl + 1) <= score) lvl++;
  return lvl;
}
export function knobsForLevel(level: number): Knobs {
  const k = level - 1;
  const all: ZombieType[] = ["walker", "runner", "brute"];
  return {
    level,
    spawnIntervalMs: clamp(1600 - 90 * k, 450, 1600),
    maxZombies: Math.min(2 + Math.floor(0.75 * k), 8),
    leapAccuracy: clamp(0.55 + 0.05 * k, 0, 0.95),
    cruiseSpeed: clamp(28 + 1.5 * k, 28, 52),
    obstacleDensity: clamp(0.4 + 0.08 * k, 0, 1),
    types: all.filter((t) => level >= D.unlockLevel[t]),
  };
}
```

```ts
import { CONFIG } from "../config";
const C = CONFIG.car;
const RAIL_X = CONFIG.road.halfWidth;

export type CarSide = "left" | "right";
export type CarEvent = { kind: "scrape"; side: CarSide } | { kind: "flipped" };
export type CarState = { /* fields as declared in Interfaces */ };

export function createCar(cruiseSpeed: number): CarState {
  return { x: 0, vx: 0, speed: cruiseSpeed * 0.85, tilt: 0, leftWeight: 0, rightWeight: 0, flipTimer: 0, alive: true, scrapeCooldown: 0 };
}

export function addWeight(car: CarState, side: CarSide, w: number) { car[side === "left" ? "leftWeight" : "rightWeight"] += w; }
export function removeWeightFrom(car: CarState, side: CarSide, w: number) {
  const k = side === "left" ? "leftWeight" : "rightWeight";
  car[k] = Math.max(0, car[k] - w);
}

export function stepCar(car: CarState, steer: number, dt: number): CarEvent[] {
  const events: CarEvent[] = [];
  if (!car.alive) return events;

  // longitudinal: ease toward cruise handled by caller setting target; here simple approach:
  car.speed += 0; // caller adjusts speed; sim keeps constant unless scrape penalty below

  // lateral steering
  const targetVx = steer * C.steerMaxSpeed;
  const dv = clampMag(targetVx - car.vx, C.steerAccel * dt);
  car.vx += dv;
  car.x += car.vx * dt;

  // rails: press past edge -> clamp, bounce inward, emit periodic scrape
  car.scrapeCooldown -= dt;
  for (const side of ["left", "right"] as const) {
    const limit = -(RAIL_X - C.halfWidth);
    if ((side === "left" && car.x < limit) || (side === "right" && car.x > -limit)) {
      car.x = clamp(car.x, limit, -limit);
      car.vx = side === "right" ? -C.railBounceVx : C.railBounceVx;
      if (car.scrapeCooldown <= 0) {
        car.scrapeCooldown = C.scrapeTickS;
        car.speed = Math.max(12, car.speed - C.scrapeSpeedLoss);
        events.push({ kind: "scrape", side });
      }
    }
  }

  // tilt toward weight-driven equilibrium; flip after sustained critical imbalance
  const imbalance = (car.rightWeight - car.leftWeight) / C.capacityPerSide;
  const target = clamp(imbalance, -1, 1);
  car.tilt += clamp(target - car.tilt, -C.tiltRate * dt, C.tiltRate * dt);
  if (Math.abs(imbalance) >= 1) {
    car.flipTimer += dt;
    if (car.flipTimer >= C.flipWindowS) {
      car.alive = false;
      events.push({ kind: "flipped" });
    }
  } else {
    car.flipTimer = Math.max(0, car.flipTimer - 2 * dt);
  }
  return events;
}
const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));
function clampMag(v: number, m: number) { return clamp(v, -m, m); }
```

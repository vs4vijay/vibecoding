## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Denial of Service | parseFile.ts state machine | medium | mitigate | Cap maxLinesPerMessage at 1000 continuation lines to prevent message concatenation OOM. ParseFile tracks continuation count and truncates beyond threshold, appending "[truncated...]" to text. |
| T-01-02 | Tampering | normalize.ts | low | mitigate | Normalization is scoped to header region (timestamp + sender) only. Message body is NOT normalized to preserve fidelity of original content. Verify in implementation that normalize only transforms the prefix region and leaves body intact. |
| T-01-03 | Denial of Service | patterns.ts regex matching | low | mitigate | All regex patterns use bounded quantifiers (\d{x,y}) and explicit delimiters. No nested quantifiers or backreferences that could cause catastrophic backtracking. Verify with regex safety check during review. |
| T-01-04 | Information Disclosure | classify.ts, dedup.ts | low | accept | Dedup hashing uses FNV-1a not SHA-256. FNV-1a is a non-cryptographic hash — it is used for deduplication, not security. No sensitive data is cryptographically processed. Acceptance rationale: FNV-1a is well-suited for its intended dedup purpose per research recommendation; SHA-256 upgrade path exists if needed. |
| T-01-SC | Tampering | npm/pip installs | high | mitigate | Only vitest and @biomejs/biome as dev dependencies. Both are verified in RESEARCH.md Package Legitimacy Audit table with [OK] verdict. No runtime dependencies to audit. Verification via `bun install --frozen-lockfile` after install. |
</threat_model>
